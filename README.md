# TCMNP

**Traditional Chinese Medicine Network Pharmacology** — 中药网络药理学可视化分析工具包。

## 简介

TCMNP 提供中药复方/单药的网络药理学分析可视化功能（成分-靶点网络、富集分析、PPI、韦恩图、桑基图等 38 个绘图与查询函数），内置多数据库整合的知识库快照。
